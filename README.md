# トーク分析 — Talk Log Analyzer

[![CI](https://github.com/yutopias09/talk-log/actions/workflows/ci.yml/badge.svg)](https://github.com/yutopias09/talk-log/actions/workflows/ci.yml)

LINEのトーク履歴（テキスト書き出し）を読み込んで、ふたりの会話を可視化するローカル分析ツールです。
データはブラウザの中だけで処理され、サーバーへの送信は一切ありません。

公開版: <https://yutopias09.github.io/talk-log/>
2026/11/26 ver1.0.3
2026/11/25 ver1.0
## すぐに使う

`index.html` または `line_chat_analyzer_web.html` をブラウザで開くだけです。
どちらもビルド済みの単一HTMLなので、ローカルサーバーやインストールは不要です。
ファイルを開いたら「サンプルで試す」で動作を確認できます。

1. LINEのトーク画面右上の設定を開く
2. 「トーク履歴を送信」→「テキストファイル」を選ぶ
3. 保存した `.txt` ファイルを画面にドロップ（または「ファイルを選ぶ」）

対応している書き出し形式:

- 標準形式: `2025/12/06(土)` の日付行 + `21:09\t名前\t本文`
- スペース区切り形式: `2025.12.06 土曜日` の日付行 + `21:09 名前 本文`
- 12時間表記: `2023/07/31(月)` の日付行 + `午後05:40	名前	本文`（午前／午後）
- 文字コード: UTF-8 / Shift-JIS / UTF-16 を自動判定

##　今回のアップデートの更新内容

[言葉]
-言葉の推移: 好きな言葉を入れると、月ごとに何回使ったかがグラフで見られます。はじめて使った日、いちばん使った月、最後に使った日も出ます。
-ふたりの口ぐせ: 相手よりも自分のほうが特によく使う言葉を、人ごとに出します。
-共有したリンク: トークに出てきたURLを、お店・地図・買い物・音楽などの種類に分けて一覧にします。

[通話]
-通話した回数、合計の通話時間、いちばん長い通話、1時間以上の長電話の回数
-長電話ランキング
-かけるのはどっち？（不在着信・キャンセルの回数も）
-通話する時間帯、曜日、月ごとの通話時間

[思い出]
-○年前の今日、○ヶ月前の今日のトーク
-記念日カウントダウン（付き合った日や誕生日を登録できて、この端末に保存されます）
-いちばんやりとりが空いた期間（途切れる前の最後のメッセージと、再開した最初のメッセージ）
-はじめての記録（はじめての「好き」「ありがとう」、最初の写真・スタンプ・通話など。自分で言葉を入れて探すこともできます）
-年ごとのまとめ

[画面の表示変更]
-ホーム: 読み込んだトークを端末に保存しておけます。次からはファイルを選ばずに「前回のトーク」からすぐ開けます。保存したトークは削除もできます。
-概要: ○年前の今日にやりとりがあると、いちばん上でお知らせします。
-内訳:よく使った言葉を、人ごとに切り替えて見られるようになりました。
-会話のくせ：先に話しかけるのは、会話を締めるのは、先に「おはよう」「おやすみ」を言うのは、続けて送る数
-相性レポート：やりとりのバランスと返信の速さから判定
-履歴:お気に入りの日と、日ごとのメモ（端末に保存）
-ランダムで思い出の日を開く
-日付ジャンプ
-CSVで保存
-送信者で絞り込むと正しく表示されない不具合を修正
-月別: 今月の目標（達成するとお祝い）
-連続記録: お祝いの演出を追加しました。日付が1日ずれることがある不具合も直しました。
-再生:期間を選べます（1日／1週間／2週間／1ヶ月／全期間）
-スピードは4段階
-「しゅぽっ」の効果音（オン・オフできます）
-残り時間のめやす
-長い期間でも軽く動きます
-シェア: 「ストーリーで振り返る」を追加しました。インスタのストーリーのような全画面スライドで、ふたりのトークを振り返ります。メッセージ数、打った文字数（文庫本何冊分か）、話す割合、曜日・時間帯、連続記録、よく使った言葉、周年が出て、最後に紙吹雪が舞います。

[全体の改善点]
-ガラスのスライダー: タブと下のメニューを、透明なガラスがスライドするデザインにしました。軽く動いて、タップすると音と振動があります。
-絵文字の数え方: 肌の色つきや、組み合わせてできている絵文字も、1つとして正しく数えます。
-コピー防止: 長押ししても文字を選択・コピーできないようにしました。
-グラフをなぞったときの数字: 大きく表示するようにしました。曜日つきの日付と人ごとの件数が出て、指を離しても少しのあいだ残ります。なぞると軽く振動します。
-ホーム画面に追加: アイコンつきで、アプリのように使えます。
-サンプルデータ: 通話やリンクの例を追加しました。

## 主な機能

| 画面 | 内容 |
| --- | --- |
| 概要 | 期間のメッセージ数・文字数・ピーク時間、推移チャート（なぞると日付・件数・ふたりの内訳）、ふたりの割合、盛り上がった話、直近7日間、○年前の今日のお知らせ |
| 詳細統計 | 返信スピード、生活タイプ診断、文字数の推移、メッセージ種類、最多・最少日 |
| 時間帯分析 | 24時間の分布、時間帯の内訳、曜日×時間帯ヒートマップ |
| 内訳・ランキング | メッセージ種別、よく使う言葉（カタカナ語はそのまま1語・送信者別に切替）、絵文字（合成絵文字も1つとして数える）、話題分類、絵文字の推移、会話のくせ（話しかける・締める・先におはよう／おやすみ・連投）、相性レポート |
| ことば | 言葉の推移（好きな言葉の月ごとの回数・はじめて使った日）、ふたりの口ぐせ、共有したリンク集 |
| 通話の記録 | 通話回数・合計時間、長電話ランキング、かけるのはどっち、時間帯・曜日・月ごとの通話 |
| 思い出 | ○年前の今日、記念日カウントダウン（端末に保存）、いちばん空いた期間、はじめての記録、年ごとのまとめ（年ごとのストーリー） |
| 日別履歴 | 日ごとの一覧、絞り込み、並び替え、その日のメッセージ表示、お気に入り・メモ（端末に保存）、思い出をひらく（ランダム）、日付ジャンプ、CSV保存 |
| 連続記録 | いまの記録・最長記録・次の目標、直近60日、マイルストーン、記念日のお祝い（紙吹雪） |
| カレンダー | 月ごとのヒートマップ、日付ごとのメッセージ |
| 月次トレンド | 今月の目標と月末の見込み、月ごとの増減、月別内訳、累計 |
| キーワード検索 | 送信者・種類で絞り込める全文検索、ハイライト |
| 比較 | 前期間との比較、または別のトークファイルとの比較 |
| シェアカード | ストーリーで振り返る（全画面スライド）、4:5 / 1:1 / 9:16 の画像を生成。3テーマ、PNG保存・共有 |
| トーク再生 | 1日〜全期間の会話を再生（ゆっくり／ふつう／はやい／超はやい）、送信音つき |

デスクトップでは左サイドバー＋マルチカラム、スマートフォンでは下部タブ＋メニューシートに切り替わります。
期間の切り替えや下部タブは、クリアガラスの枠をタップ・なぞって動かせます（タップ音・振動つき）。
画面の文字は長押し・右クリックでコピーできないようにしています（検索欄やメモなどの入力欄は除く）。

読み込んだトークは、希望すればこの端末（ブラウザのIndexedDB）にだけ保存され、次回は「すぐに開く」で開けます。保存はトップ画面からいつでも削除できます。
GitHub Pages で公開している場合は、ホーム画面に追加してアプリのように使え、一度開けばオフラインでも起動します（`manifest.webmanifest` / `sw.js` / アイコン画像を `index.html` と同じ場所に置いてください）。
ライト／ダークテーマに対応し、配色は WCAG AA のコントラストを満たすよう調整しています。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173 （/ は app.html へ内部リダイレクト）
npm run build    # 型チェック → 単一HTMLを index.html / line_chat_analyzer_web.html / dist/index.html に生成
```

### 構成

```
app.html               Vite の開発エントリ（ソース）
index.html             ビルド済みアプリ（GitHub Pages が配信するルート）
line_chat_analyzer_web.html  同じビルドの単一HTML（従来のファイル名）
src/
  App.tsx              アプリシェル、ファイル読み込み、画面切り替え
  nav.ts               画面定義とナビゲーション
  styles.css           デザイントークンと全スタイル
  lib/
    parse.ts           LINEトーク履歴パーサー（タブ区切り／CRLF／Shift-JISフォールバック）
    analytics.ts       集計ロジック（連続記録、時間帯、返信速度、ランキング、話題、盛り上がり検出など）
    share.ts           シェアカードのCanvas描画
    useStats.ts        期間スライスとテーマ／保存状態のフック
    sample.ts          サンプルデータ生成
  components/          アイコン、汎用UI、SVGチャート
  views/               12画面
scripts/
  copy-single.mjs      ビルド結果を単一HTMLとして配置・検証
legacy/
  line_chat_analyzer_web.html   旧・単一HTML版（参考用）
```

- React 18 + TypeScript + Vite
- チャートは外部ライブラリを使わない手書きSVG（軽量・テーマ追従・スクリーンリーダー向けの説明付き）
- シェアカードは Canvas 2D で描画し、端末内でPNG化
- 単一HTML出力は `vite-plugin-singlefile`

## 公開（GitHub Pages）

GitHub Pages は **main ブランチのルート** を配信する設定です。ルートの `index.html` が
そのままアプリになるため、追加のデプロイ設定なしで公開されます。

```bash
npm run build
git add index.html line_chat_analyzer_web.html
git commit -m "Rebuild standalone HTML"
git push
```

push すると GitHub の Pages ビルドが走り、数十秒で反映されます。

## CI

`.github/workflows/ci.yml` が push / pull request 時に次を実行します。

- `npm ci` → 型チェック → 単一HTMLビルド
- 生成物が自己完結していること（外部アセット参照がないこと）を検証
- コミット済みの `index.html` / `line_chat_analyzer_web.html` がビルド結果と一致するか検証
  （古い場合は失敗するので、`npm run build` してコミットしてください）
- ビルド済みHTMLを Actions の Artifacts にアップロード

## プライバシー

- 読み込んだファイルは `FileReader` でブラウザ内だけに読み込まれます
- 解析結果・カード画像はどこにもアップロードされません
- Webフォント（Google Fonts）だけは読み込み時に通信します。オフラインでもシステムフォントで動作します
